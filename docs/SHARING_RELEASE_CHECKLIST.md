# Sharing release acceptance — manual gates

Status: NOT RUN. Local headless Chrome copy/read/paste and scripted fixtures are
not acceptance of X's composer or a physical mobile share target.

Record candidate SHA, deployed web SHA, device/OS/browser, date, result and issue.
Use a non-sensitive meme and operator-owned accounts. Never publish merely to test;
verify draft attachment then discard. Do not record account/session credentials.

## Desktop Chrome/Edge

1. Open Share, Copy image for X. Verify permission denial offers Download image.
2. Allow copying, open X draft manually, paste with Ctrl+V/Cmd+V. Confirm actual
   image attachment matches selected meme, not URL text. Discard draft.
3. Repeat after Next/Previous and on gallery slide two. Check exact selected image.
4. Download image, attach manually in X, confirm artwork and discard. Verify actual
   filename/file content, not only the app's "download requested" message.
5. Animated input: confirm still-frame copy warning; use file download for animation.
6. Close/Escape returns focus; panel remains usable at true 200% browser zoom.

## Safari/Firefox desktop

Repeat copy or documented unsupported fallback; never claim support solely from
API presence. Validate permissions, paste target, file download and keyboard focus.

## iOS Safari / Android Chrome

1. Share image prepares file; second click opens native sheet. Choose X if offered.
2. Confirm actual image in composer matches selected artwork; discard, do not post.
3. Cancel sheet and retry. No false success or automatic fallback download.
4. Gallery active slide, Next during preparation, removed/broken media, slow network.
5. X absent/unsupported files: download instructions remain usable.

## Link-only and previews

Tweet link is explicitly text/link only. Validate readable title and exact stable
URL after navigation. Verify approved PUBLIC_ORIGIN and deployed metadata; X card
cache/rendering is independent from actual media attachment. No forced preview claim.

## Release blockers

Wrong image/identity, stale download target, private data in shared text, silent
failure, false "posted" confirmation, inaccessible recovery or stranded focus.
Stop rollout, preserve minimal private evidence and revert candidate through normal
approved process. Do not enable feed flags or alter credentials for these tests.

## Product observation

With 5–8 consented target users, ask "send this image" versus "send this exact
link" without coaching. Record completion/hesitation and whether users distinguish
actions. Small study diagnoses confusion, not retention lift. Combine with existing
100-selection content baseline before choosing the next discovery experiment.
